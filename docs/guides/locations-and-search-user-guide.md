# Locations (sedes) and business search (user guide)

## For business owners: my locations
1. Sign in and open **My business → Settings → Locations** (`/partner/settings/locations`).
2. Press **Add location**, choose the **city** from the list, type the **address** (both required) and, if you want, a branch name, postal code and phone.
3. Tick **This is the main location** to make it the main one. Your first location is always the main one.
4. Each location has **Edit**, **Make main** (not on the main one) and **Delete**. Delete asks for confirmation. If you delete the main location, the oldest remaining one becomes the main one.

| Situation | What you see |
| --- | --- |
| No business registered yet | A message asking you to register one |
| City or address missing | The field is marked and nothing is sent |
| The server refuses (not the owner, invalid data) | An error message; the form stays open so you do not lose what you typed |
| Your cities are not listed | Only the catalogue cities can be chosen; ask the Directory team to add one |

## For visitors: search businesses
- Type in the search box of the header and press Enter: the **search page** opens with that text.
- On the page, narrow down by **city**, **category** and **text**, and move through the pages with **Previous / Next**.
- The address bar keeps your filters, so you can copy the link or come back with the browser's back button.
- Each result shows its category, whether it is verified and its locations.
